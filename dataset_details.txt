

Dataset Details

Project Title:
Predicting Urban Bike Sharing Demand Using Weather, Seasonal, and Calendar-Based Machine Learning Features

This project uses two publicly available bike-sharing datasets. The Seoul Bike Sharing Demand dataset is used as the main dataset for model development, while the Washington D.C. Bike Sharing dataset is used as a parallel dataset for comparison and validation.

------------------------------------------------------------
1. Primary Dataset: Seoul Bike Sharing Demand Dataset
------------------------------------------------------------

Dataset Name:
Seoul Bike Sharing Demand Dataset

Dataset Source:
UCI Machine Learning Repository

Dataset Link:
https://archive.ics.uci.edu/dataset/560/seoul+bike+sharing+demand

Description:
The Seoul Bike Sharing Demand dataset contains hourly bike rental records from the Seoul bike-sharing system. It includes weather, seasonal, holiday and operational information that can be used to predict hourly bike rental demand.

Main Target Variable:
Rented Bike Count

Main Features:
- Date
- Hour
- Temperature
- Humidity
- Wind speed
- Visibility
- Dew point temperature
- Solar radiation
- Rainfall
- Snowfall
- Seasons
- Holiday
- Functioning Day

Use in Project:
This dataset was used as the main dataset for preprocessing, exploratory data analysis, feature engineering, model training, model evaluation, cross-validation, feature-importance analysis and ablation testing.

Models Applied:
- Linear Regression
- Random Forest
- Gradient Boosting
- XGBoost

Best Performing Model:
XGBoost

Best Seoul Result:
MAE = 94.535
RMSE = 161.006
R2 Score = 0.938

------------------------------------------------------------
2. Parallel Dataset: Washington D.C. Bike Sharing Dataset
------------------------------------------------------------

Dataset Name:
Bike Sharing Dataset / Capital Bikeshare Hourly Dataset

Dataset Source:
UCI Machine Learning Repository

Dataset Link:
https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset

Description:
The Washington D.C. Bike Sharing dataset contains hourly rental records from the Capital Bikeshare system. It includes time, calendar and weather-related variables that are useful for bike-sharing demand prediction.

Main Target Variable:
cnt

Renamed Target Variable in Project:
Rented_Bike_Count

Main Features:
- Date
- Season
- Year
- Month
- Hour
- Holiday
- Weekday
- Working day
- Weather situation
- Temperature
- Feeling temperature
- Humidity
- Wind speed

Important Preprocessing Note:
The columns casual and registered were removed because they directly contribute to the target variable cnt. Keeping these columns would cause target leakage.

Use in Project:
This dataset was used as a parallel dataset to test whether the machine learning workflow developed on the Seoul dataset could also perform effectively on another city’s bike-sharing data.

Models Applied:
- Linear Regression
- Random Forest
- Gradient Boosting
- XGBoost

Best Performing Model:
XGBoost

Best Washington D.C. Result:
MAE = 25.717
RMSE = 40.549
R2 Score = 0.948

------------------------------------------------------------
3. Purpose of Using Two Datasets
------------------------------------------------------------

The Seoul dataset was used as the primary dataset for the main machine learning implementation. The Washington D.C. dataset was added as a parallel dataset based on supervisor feedback.

The purpose of using the second dataset was to:
- test the developed workflow on another city’s bike-sharing data;
- compare model performance across two datasets;
- perform additional cross-validation;
- strengthen the reliability of the project findings;
- show that the modelling approach is not limited to only one dataset.

------------------------------------------------------------
4. Final Note
------------------------------------------------------------

Both datasets are publicly available and were used only for academic research purposes. The project does not use personal or sensitive user information.
